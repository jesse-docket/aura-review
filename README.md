# aura-review

Review page for the Aura agent trajectory and the proposed prompt, configuration and knowledge-base changes. Live at https://jesse-docket.github.io/aura-review/

Each section has its own threaded feedback box, backed by GitHub Discussions (category: Feedback) via giscus. Anyone with a GitHub account can comment or reply. Edit `index.html` to change the page; do not rename the `data-term` values on the comment boxes once threads exist.

Customer emails and pricing figures are redacted from the page because this repo is public.
